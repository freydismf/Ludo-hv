# Lúdó

## Lýsing
Lúdó er borðspil unnið í JavaFX þar sem notandi spilar á móti tölvu
Verkefnið er byggt á verkefni 2 í HBV201G 

Höfundar: Freydís María og Hrefna Sóley


## Áður en forrit er keyrt
Til þess að keyra forritið þarf að setja upp IntelliJ IDEA eða annað þróunarumhverfi sem getur keyrt
JavaFX. Einnig þarf að vera með JDK 23 eða nýrra

Einnig þarf hafa eftirafrandi
- Java 25.0
- JavaFX 25.0
- Maven 4.0.0

## Keyrsla
- Opnaðu Maven tool window, lengst til hægri
- farðu í plugins
- farðu í javafx
- tvísmelltu á javafx:run
